# Revision and human feedback

Use this guide for substantial drafts or an ongoing writing collaboration. Scale it down for a short, self-contained request.

## Start from the current text

Confirm the relevant version before editing a shared document. Existing reader comments, tracked changes and authorised wording are part of the source, not clutter to remove. Preserve them unless the user explicitly asks for a defined change. If live content has changed since a local copy was prepared, reconcile it before applying the revision.

Distinguish the writer's intended argument from what the current wording happens to suggest. If a revision would select between materially different interpretations, ask a focused question or present the alternatives. Do not silently resolve a substantive ambiguity as a stylistic choice.

## Choose the level of review

Paragraph-by-paragraph discussion helps when the writer is settling an argument, testing a voice or choosing how to explain a difficult concept. Once the approach is agreed, a selective section or document pass usually reveals continuity problems more effectively. Do not keep reopening accepted passages without a concrete reason.

For a larger pass, make a short reverse outline and identify the highest-impact issues. These might be an unexplained change of subject, repeated announcement sentences, a comparison with mismatched assumptions, or detail whose relevance is not yet clear. Revise those areas first and leave successful prose intact.

If the user wants diagnostic feedback only, describe the issue and its effect on the reader, then suggest a bounded remedy. Do not deliver an unsolicited replacement document. If revision is authorised, make the changes and identify substantive decisions that remain with the writer.

## Use feedback that identifies the problem

Invite concrete reader reactions where helpful. The writer does not need to prescribe the wording. Useful comments include:

- "I lose the connection between this result and the next paragraph."
- "I understand the number, but not why the difference matters."
- "This sounds more certain than the evidence allows."
- "This is too formal for the recipient."
- "Keep this short sentence; it carries the emphasis I want."
- "I need the term explained before this example."

Translate feedback into the smallest effective revision, then check the surrounding passage. Do not turn a comment about one sentence into a global rule. Where feedback conflicts, identify whether the conflict concerns meaning, audience, structure or preference before choosing a remedy.

## Separate writing judgement from model output

Use AI for bounded tasks such as finding unclear connections, proposing alternatives, summarising a paragraph's function or checking whether a revision changed a qualification. The writer retains responsibility for the argument, evidence and final wording.

For consequential or heavily revised passages, compare the original and revised text for claim strength, numerical meaning, citation support and omitted exceptions. An independent reader or reviewer can help identify drift, but agreement between models is not verification of a source.

If time permits, suggest a fresh reading after a break as a useful option. The writer should read once for the argument and once for precision, rather than trying to evaluate every sentence, citation and layout choice simultaneously. Do not make a delay or approval cycle mandatory when the user has authorised completion.

## Preserve a reviewable result

Use tracked changes or a comparison when requested and supported by the editing tools. A clean reading copy can complement a marked copy if the user asks for both. Preserve the relationship between the versions so that feedback is applied to the right text.

Do not delete comments, accept revisions or replace shared files merely to make review easier. Those actions need their own task authority. When authorised, verify the actual saved result and report any unresolved discrepancy. Document-format checks belong to the relevant file workflow; a language review alone does not establish correct pagination or successful upload.

## Final review prompts

Use these as questions, not a scorecard that every sentence must satisfy:

1. Can the intended reader state the passage's point and follow how it develops?
2. Are links between ideas supported and specific?
3. Does each result have enough explanation for its use here?
4. Have facts, qualifications, citations and the writer's commitments survived?
5. Does the voice fit the relationship and medium?
6. Have effective passages been left alone, and material open questions been made visible?
