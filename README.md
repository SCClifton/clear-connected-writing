# Clear Connected Writing

A portable writing skill for explanatory prose, academic synthesis, professional communication and personal messages. It favours meaningful connections and natural sentence rhythm while preserving facts, qualifications, citations and the writer's voice.

## Contents

Start with [SKILL.md](skills/clear-connected-writing/SKILL.md). Supporting guides cover paragraph continuity, audience and evidence, revision with human feedback, invented examples and public writing sources. The skill has no scripts, network calls, account dependencies or private document dependencies.

## Use

For a Codex installation that discovers user skills in `~/.codex/skills`, copy the complete `skills/clear-connected-writing` folder there. Keep the relative layout so the supporting references remain available. Follow the host's current skill-discovery instructions if its location differs.

Example request:

> Use $clear-connected-writing to selectively revise this section. Improve the connections between ideas, preserve the technical meaning and citations, and leave effective passages alone.

For another tool, use its supported skill mechanism or provide `SKILL.md` and the relevant linked guides as instructions. Product-specific UI metadata is optional outside Codex. The underlying method is ordinary Markdown, but automatic discovery and invocation vary by product.

## Privacy and maintenance

The instructional files use generic, invented examples. They contain no personal profiles, employer details, private source excerpts, account identifiers or machine-specific paths. Generic installation paths are included only to explain use.

Keep future additions equally portable. Do not copy real correspondence, document comments, transcripts, credentials or private examples into this repository. Review file names, links, hidden files and version history before any public release. Check archive contents as well as the current working tree.

A repository's owner, activity and commit metadata can identify its maintainer even when the files are generic. Private repository access and a public release are separate decisions. A public edition should contain only reviewed files with fresh history; do not mirror private history automatically.

This repository does not grant permission to move workplace material between systems. Use it within the policies of the environment where it is installed. No public redistribution licence has been selected yet.
